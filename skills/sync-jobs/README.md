# sync-jobs

Version 2: skill-owned acquisition, sync and optional triage. Start with
`SKILL.md`. The public package contains a synthetic example profile only; real
candidate profiles are private installation-local overlays. Live data remains
in the selected workspace, and retired project scripts are not dependencies.
The generic triage engine accepts legacy and newer profile result columns.
Read `references/profile_compatibility.md` before carrying a private profile
across an engine update; profile selection and policy rules stay local.
