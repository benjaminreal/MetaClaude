# Direct-source intake

Use this mode only for owner-selected employer, ATS, or third-party job-board URLs outside the LinkedIn numeric-ID sync. It archives one unambiguous job posting and appends one tracker row without changing the external site. Prefer a complete `SourcePostingAcquisitionV2` bundle produced by `acquire-url`; compatible legacy direct records remain supported.

Legacy input is `{"records":[...]}`. Each record supplies `title`, `company`, `location`, `url`, `description`, browser `provenance`, and `quality_evidence` under the normal capture-quality contract. Its optional `source_id` retains the historical `ext-` plus the first 20 hexadecimal characters of SHA-256 over the legacy canonical URL. A complete `SourcePostingAcquisitionV2` bundle instead derives its `source_id` from provider plus stable provider job ID, or its source canonical URL when no stable ID exists. A careers landing page is not a posting unless the captured title and description bind one specific open role.

Run `external-ingest` without `--commit` first. It revalidates V2 selection coverage, bundle and record hashes, embedded quality and every record. V2 uses the acquisition canonicalizer unchanged and treats provider plus stable provider job ID as primary identity, with canonical URL fallback. Existing `PostingSourceProvenanceV2` sidecars supply URL aliases, so a stable ID survives a changed URL while a URL rebound to a conflicting stable ID stops. A legacy tracker/archive match that would gain a V2 stable identity fails explicitly with `identity_upgrade_required`; it is never reported as already present while silently discarding that identity. Legacy records retain their historical canonicalizer and URL-derived IDs. Both legacy and V2 batches reject embedded credentials, secret/session query keys, and common path/matrix session IDs before staging. The command stages Markdown, source-provenance, compensation and eligibility sidecars plus a workbook copy and reports intended rows. A batch with failures, dropped selections, duplicate/conflicting identities, incomplete descriptions, an Excel lock, or partial tracker/archive state stops. After inspection, add global `--commit`. The commit backs up the tracker, publishes source-bound sidecars, extends `JobsTable`, and verifies readback. It never applies, messages, saves or unsaves anything online.

The current workbook retains its historical `Link puesto linkedin` header. A V2 direct-source row leaves that cell blank and writes the canonical external posting URL to `Link puesto empresa`; the worklist uses the employer URL and binds eligibility evidence to it. `PostingSourceProvenanceV2` separately preserves discovery, final and canonical URLs, provider identity and attempts. Legacy V1 direct-record inputs retain their historical behavior of storing the URL in both columns for compatibility. All untrusted workbook text uses one literal-text writer that forces the Excel string type: the original valid text, including formula-shaped prefixes and leading whitespace, survives save/reload exactly while remaining non-formula. Only XML-illegal controls are replaced. Typed numeric/date cells are not converted.
