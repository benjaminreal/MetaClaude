# Stage 1 Delta Capture — Candidate 1.0.0

**Date:** 2026-08-21

Tacit decisions exposed and externalized:

- `target_id` is canonical; `source_tracker_id` is optional provenance, never an implicit alias.
- A target is incomplete without local authority receipts, owner scope, intake mode, structured reporting hypotheses, and complete capability receipts.
- Capability is six-state, not boolean; each non-available state has a named readiness/fallback ceiling.
- Guards marked `CLEAR` require five current evidence receipts, not assertion-only booleans.
- Authenticated currentness binds capability, surface identity, recipient/company/target, result, evidence hash/ref, run, and freshness through review.
- Hunter can occur only after guards, a defensible route or documented exception, currentness, hook/proof, and first-party email miss/block.
- `DRAFT_READY_VERIFY_CHANNEL` requires a non-`NONE` channel with an address or route.
- Selected hook evidence matches one intent on ID, exact URL, content hash, and run ID.
- Intent identity derives from structured subject/claim/surface family; query rephrasing cannot create exhaustion.
- Candidate proof, access limitations, and owner summary are explicit dossier sections.
- Independent review is a separate record bound to the canonical dossier subject hash with per-check evidence.
- V2 remains frozen history; V3 requires fresh evidence and the validator refuses silent reinterpretation.
- Local green tests prove mechanics and internal consistency only.
